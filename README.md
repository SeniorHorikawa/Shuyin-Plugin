## ✨ 功能一览

| 模块 | 能力 |
| :-- | :-- |
| 📚 **小说搜索** | 一次关键词同时搜番茄 + 七猫，合并转发成卡片列表，含作者 / 章节数 / 状态 / 评分 / 简介 |
| 📥 **整书下载** | 起点、七猫、番茄三站整本抓取，导出为 `.zip` 直接发文件；支持限量下载与断点式缓存 |
| 🔗 **链接直下** | 直接发起点 / 七猫 / 番茄分享链接（含短链）即可识别书号并下载 |
| 🎵 **酷狗登录** | 二维码扫码登录，轮询确认、可取消，ck + 设备信息本地持久化 |
| ⏱️ **酷狗刷歌** | 提交指定时长刷歌，自动计算预计耗时并在完成后回报今日听歌增量 |
| 👤 **账号信息** | 查询昵称、听歌等级、今日 / 累计听歌时长、地区、注册时间等 |
| ♟️ **五子棋** | 人机对弈，简单 / 普通 / 困难三档难度；棋盘图片带 X/Y 坐标轴，AI 落子坐标实时展示 |

## 📦 安装

> 前置：已部署 [TRSS-Yunzai](https://github.com/TimeRainStarSky/Yunzai) 或 [Miao-Yunzai](https://github.com/yoimiya-kokomi/Miao-Yunzai)，Node.js ≥ 18。

```bash
# 进入云崽插件目录
cd Yunzai/plugins

# 克隆本插件
git clone https://github.com/SeniorHorikawa/Shuyin-Plugin.git

# 安装依赖（插件本体近乎零依赖，仅格式化工具）
cd Shuyin-Plugin && pnpm install
```

重启云崽即可自动注册使用。

## ⚙️ 配置

配置文件位于**插件目录**下，首次加载时若不存在会自动生成模板：

```text
Yunzai/plugins/Shuyin-Plugin/config/novel.yaml
```

| 字段 | 类型 | 说明 |
| :-- | :-- | :-- |
| `api_url` | string | 后端网关地址（番茄 / 七猫 / 起点 / 酷狗 / 五子棋 action 共用），默认 `http://127.0.0.1:2017` |
| `QIDIAN_CK` | string | 起点读书完整请求头（含 `QDInfo` 等），仅在下载起点书籍时需要 |
| `search_count` | number | 每个来源返回的搜索结果条数 |
| `cache_minutes` | number | 搜索缓存有效分钟数，缓存期内可用「序号」直接下载 |
| `download_timeout_sec` | number | 整书下载 HTTP 超时（秒），大部头可调大 |
| `max_chapters` | number | 番茄整书默认最大章节数，`0` 表示全本 |
| `size_warn_mb` | number | 发送前超过该大小（MB）时提示 |
| `gomoku_recommend` | boolean | 五子棋「推荐落子（辅助）」的默认开关（新用户默认值），运行时可用 `#五子棋开启辅助/关闭辅助` 按用户单独切换 |

> 🔐 `config/novel.yaml` 含敏感信息，已在 `.gitignore` 中忽略，请勿提交到仓库。

## 🎮 使用指令

> 💡 **交互按钮**：发送 #小说帮助 / #酷狗帮助 / #五子棋帮助 可打开快捷操作栏；小说搜索结果和五子棋棋盘消息也会附带按钮。若当前适配器不支持按钮，原指令仍可正常使用。

### 📚 小说

| 指令 | 说明 |
| :-- | :-- |
| `#搜小说 <关键词>` | 同时搜索番茄 + 七猫 |
| `#搜番茄 <关键词>` / `#搜七猫 <关键词>` | 指定单一来源搜索 |
| `#小说下载 <序号> [章节数]` | 下载搜索结果（限量仅番茄支持） |
| `#小说下载 番茄:<书号> [章节数]` | 指定来源 + 书号下载 |
| `#小说下载 七猫:<书号>` / `#小说下载 起点:<书号>` | 同上 |
| `#起点下载 <书号>` / `#七猫下载 <书号>` / `#番茄下载 <书号>` | 快捷下载 |
| `<分享链接>` | 直接发起点 / 七猫 / 番茄链接即可下载整本 |
| `#小说帮助` | 查看指令菜单 |

### 🎵 酷狗

| 指令 | 说明 |
| :-- | :-- |
| `#酷狗登录` | 生成二维码，扫码并确认登录 |
| `#酷狗取消登录` | 取消进行中的扫码登录 |
| `#酷狗提交刷歌 <分钟> [歌名]` | 提交刷歌任务，歌名不填默认《晴天》 |
| `#酷狗停止刷歌` | 提前停止当前刷歌任务 |
| `#酷狗刷新` | 刷新 ck 并返回账号信息 |
| `#我的酷狗` | 查看等级、今日 / 累计听歌时长等 |
| `#酷狗帮助` | 查看指令菜单 |

### ♟️ 五子棋

| 指令 | 说明 |
| :-- | :-- |
| `#五子棋` | 开始一局（已开局则查看当前棋盘） |
| `#五子棋开始 [难度]` | 新开一局，难度可选 简单 / 普通 / 困难 |
| `#五子棋 <坐标>` | 落子，如 `#五子棋 H8` 或 `#五子棋 8 8` |
| `#五子棋难度 <简单/普通/困难>` | 调整难度 |
| `#五子棋执黑` / `#五子棋执白` | 选择先后手 |
| `#五子棋开启辅助` / `#五子棋关闭辅助` | 开关推荐落子（辅助），按用户记忆 |
| `#五子棋重开` | 重开本局 |
| `#五子棋帮助` / `#五子棋菜单` | 查看指令菜单（图片形式） |

> 坐标说明：X = 列（1~15，左→右），Y = 行（1~15，上→下）；列也可用字母 A~O（A=1、H=8、O=15）。黑先，连续五子获胜（无禁手）。AI 落子后，棋盘图片上方会显示其坐标。菜单（`#五子棋帮助`）以棋盘同风格的图片展示。
>
> 💡 **推荐落子（辅助）**：AI 落子后会自动附带一个「💡 推荐 坐标」按钮，点一下即可按 AI 建议直接落子。开关**按用户记忆**（存在内存 Map 里，按 `user_id` 隔离），用 `#五子棋开启辅助` / `#五子棋关闭辅助` 切换；默认开启，可用 `config/novel.yaml` 的 `gomoku_recommend` 改默认值。
